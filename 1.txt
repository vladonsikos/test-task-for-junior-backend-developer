## Шаг 2 — Проверка всех 4 типов периодичности из ТЗ

ТЗ требует ровно эти типы. Проверь каждый:

### 2.1 daily — каждые N дней

```bash
# Создать
curl -s -X POST http://localhost:8080/api/v1/tasks \
  -H 'Content-Type: application/json' \
  -d '{"title":"Ежедневный обзвон","status":"new","recurrence_settings":{"type":"daily","interval":3}}' | jq .
```

Ожидания:
- HTTP 201
- В ответе есть `recurrence_settings.type = "daily"`
- В ответе есть `recurrence_settings.interval = 3`

```bash
# Проверить occurrences (каждые 3 дня)
curl -s "http://localhost:8080/api/v1/tasks/1/occurrences?from=2025-01-01&to=2025-01-31" | jq .
```

Ожидания:
- Список дат с шагом 3 дня (1, 4, 7, 10, 13, 16, 19, 22, 25, 28, 31 января — 11 дат)

### 2.2 monthly — определённое число месяца (1-30)

```bash
curl -s -X POST http://localhost:8080/api/v1/tasks \
  -H 'Content-Type: application/json' \
  -d '{"title":"Инвентаризация","status":"new","recurrence_settings":{"type":"monthly","day_of_month":15}}' | jq .
```

Ожидания:
- HTTP 201
- `recurrence_settings.day_of_month = 15`

```bash
curl -s "http://localhost:8080/api/v1/tasks/2/occurrences?from=2025-01-01&to=2025-06-30" | jq .
```

Ожидания:
- Ровно 6 дат: 2025-01-15, 2025-02-15, 2025-03-15, 2025-04-15, 2025-05-15, 2025-06-15

### 2.3 specific_dates — конкретные даты

```bash
curl -s -X POST http://localhost:8080/api/v1/tasks \
  -H 'Content-Type: application/json' \
  -d '{"title":"Конкретные даты","status":"new","recurrence_settings":{"type":"specific_dates","dates":["2025-01-10","2025-01-25","2025-02-05"]}}' | jq .
```

Ожидания:
- HTTP 201
- В ответе `dates` содержит все 3 даты

```bash
curl -s "http://localhost:8080/api/v1/tasks/3/occurrences?from=2025-01-01&to=2025-02-28" | jq .
```

Ожидания:
- Ровно 3 даты: 2025-01-10, 2025-01-25, 2025-02-05

### 2.4 even_odd — чётные/нечётные дни

```bash
# Чётные
curl -s -X POST http://localhost:8080/api/v1/tasks \
  -H 'Content-Type: application/json' \
  -d '{"title":"Отчётность по чётным","status":"new","recurrence_settings":{"type":"even_odd","parity":"even"}}' | jq .

# Нечётные
curl -s -X POST http://localhost:8080/api/v1/tasks \
  -H 'Content-Type: application/json' \
  -d '{"title":"Обход по нечётным","status":"new","recurrence_settings":{"type":"even_odd","parity":"odd"}}' | jq .
```

```bash
curl -s "http://localhost:8080/api/v1/tasks/4/occurrences?from=2025-01-01&to=2025-01-10" | jq .
```

Ожидания для even: 2025-01-02, 2025-01-04, 2025-01-06, 2025-01-08, 2025-01-10 (5 дат)
Ожидания для odd: 2025-01-01, 2025-01-03, 2025-01-05, 2025-01-07, 2025-01-09 (5 дат)

## Шаг 3 — Проверка валидации (граничные случаи)

Каждый из этих запросов ДОЛЖЕН вернуть HTTP 400:

```bash
# Неверный тип
curl -s -o /dev/null -w "%{http_code}" -X POST http://localhost:8080/api/v1/tasks \
  -H 'Content-Type: application/json' \
  -d '{"title":"Тест","status":"new","recurrence_settings":{"type":"weekly"}}'
# Ожидается: 400

# daily без interval
curl -s -o /dev/null -w "%{http_code}" -X POST http://localhost:8080/api/v1/tasks \
  -H 'Content-Type: application/json' \
  -d '{"title":"Тест","status":"new","recurrence_settings":{"type":"daily"}}'
# Ожидается: 400

# daily с interval = 0
curl -s -o /dev/null -w "%{http_code}" -X POST http://localhost:8080/api/v1/tasks \
  -H 'Content-Type: application/json' \
  -d '{"title":"Тест","status":"new","recurrence_settings":{"type":"daily","interval":0}}'
# Ожидается: 400

# monthly с day_of_month = 31
curl -s -o /dev/null -w "%{http_code}" -X POST http://localhost:8080/api/v1/tasks \
  -H 'Content-Type: application/json' \
  -d '{"title":"Тест","status":"new","recurrence_settings":{"type":"monthly","day_of_month":31}}'
# Ожидается: 400

# monthly с day_of_month = 0
curl -s -o /dev/null -w "%{http_code}" -X POST http://localhost:8080/api/v1/tasks \
  -H 'Content-Type: application/json' \
  -d '{"title":"Тест","status":"new","recurrence_settings":{"type":"monthly","day_of_month":0}}'
# Ожидается: 400

# specific_dates с пустым массивом
curl -s -o /dev/null -w "%{http_code}" -X POST http://localhost:8080/api/v1/tasks \
  -H 'Content-Type: application/json' \
  -d '{"title":"Тест","status":"new","recurrence_settings":{"type":"specific_dates","dates":[]}}'
# Ожидается: 400

# even_odd без parity
curl -s -o /dev/null -w "%{http_code}" -X POST http://localhost:8080/api/v1/tasks \
  -H 'Content-Type: application/json' \
  -d '{"title":"Тест","status":"new","recurrence_settings":{"type":"even_odd"}}'
# Ожидается: 400

# even_odd с неверным parity
curl -s -o /dev/null -w "%{http_code}" -X POST http://localhost:8080/api/v1/tasks \
  -H 'Content-Type: application/json' \
  -d '{"title":"Тест","status":"new","recurrence_settings":{"type":"even_odd","parity":"middle"}}'
# Ожидается: 400

# occurrences: from > to
curl -s -o /dev/null -w "%{http_code}" \
  "http://localhost:8080/api/v1/tasks/1/occurrences?from=2025-12-01&to=2025-01-01"
# Ожидается: 400

# occurrences: диапазон > 1 года
curl -s -o /dev/null -w "%{http_code}" \
  "http://localhost:8080/api/v1/tasks/1/occurrences?from=2024-01-01&to=2026-01-02"
# Ожидается: 400

# occurrences: без from/to
curl -s -o /dev/null -w "%{http_code}" \
  "http://localhost:8080/api/v1/tasks/1/occurrences"
# Ожидается: 400

# occurrences: неверный формат даты
curl -s -o /dev/null -w "%{http_code}" \
  "http://localhost:8080/api/v1/tasks/1/occurrences?from=01-01-2025&to=2025-01-31"
# Ожидается: 400
```

## Шаг 4 — Проверка что базовый CRUD не сломан

```bash
# Задача БЕЗ рекуррентности — должна создаваться
curl -s -X POST http://localhost:8080/api/v1/tasks \
  -H 'Content-Type: application/json' \
  -d '{"title":"Разовая задача","status":"new"}' | jq .
# Ожидается: 201, recurrence_settings отсутствует в ответе (omitempty)

# GET по ID
curl -s http://localhost:8080/api/v1/tasks/1 | jq .
# Ожидается: 200, recurrence_settings присутствует

# GET список
curl -s http://localhost:8080/api/v1/tasks | jq .
# Ожидается: 200, массив, у задач с рекуррентностью поле присутствует

# PUT — обновить задачу, не трогая рекуррентность
TASK_ID=1
curl -s -X PUT http://localhost:8080/api/v1/tasks/$TASK_ID \
  -H 'Content-Type: application/json' \
  -d '{"title":"Обновлённый обзвон","description":"новое описание","status":"in_progress"}' | jq .
# Ожидается: 200, recurrence_settings сохранились

# PUT — удалить рекуррентность
curl -s -X PUT http://localhost:8080/api/v1/tasks/$TASK_ID \
  -H 'Content-Type: application/json' \
  -d '{"title":"Обновлённый обзвон","status":"in_progress","remove_recurrence":true}' | jq .
# Ожидается: 200, recurrence_settings отсутствует

# DELETE
curl -s -o /dev/null -w "%{http_code}" -X DELETE http://localhost:8080/api/v1/tasks/999
# Ожидается: 404

curl -s -o /dev/null -w "%{http_code}" -X DELETE http://localhost:8080/api/v1/tasks/$TASK_ID
# Ожидается: 204
```
